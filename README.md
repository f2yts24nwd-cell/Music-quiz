# Music Quiz

Hör einen Ausschnitt und errate Titel, Interpret und Erscheinungsjahr.
Die Ausschnitte (30 s) kommen live von Deezer – kein Account nötig.

**Spielen:** https://f2yts24nwd-cell.github.io/music-quiz/

## Neues Genre hinzufügen
1. `genres/trance.js` kopieren, z. B. nach `genres/techno.js`, Name/Farben/Songs anpassen.
2. In `index.html` eine Zeile `<script src="genres/techno.js"></script>` neben der Trance-Zeile ergänzen.
